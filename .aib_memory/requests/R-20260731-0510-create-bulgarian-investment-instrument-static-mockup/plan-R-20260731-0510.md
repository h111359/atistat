## Goal

Create a self-contained Bulgarian static mockup under `workdir/investment_instrument/` that lets ATISTAT stakeholders directly open an analyst-first investment dashboard, explore representative Sofia apartment-analysis workflows, review the complete source requirements, and exercise bounded calculations, exports, guided help, and roadmap prioritization before committing to a production application. The work impacts only the new prototype folder and its focused automated test module; the public ATISTAT website and durable workspace context remain unchanged.

## Constraints

- Keep every runtime HTML, CSS, JavaScript, font, image, and data dependency inside `workdir/investment_instrument/`; opening `workdir/investment_instrument/index.html` through `file://` must require no server, build step, installation, CDN, or network request.
- Use Bulgarian for all user-facing interface, help, roadmap, requirements-navigation, status, warning, and export labels; stable machine-readable identifiers may use ASCII.
- Open on an Analyst Dashboard and provide a role switcher with deep Analyst coverage and lighter Administrator and Observer/Approver states.
- Use the existing ATISTAT green, ink, cream, local Cyrillic typography, and approved outlined logo treatment while clearly labeling the prototype as an internal experiment separate from the public website.
- Persist only non-sensitive demo state in versioned browser local storage, provide a visible reset, and fall back safely when storage is unavailable, full, or stale.
- Recalculate only acquisition, loan, repair, flip/rent cash flow, ROI, NPV, and selected sensitivity outputs; label advanced outputs as samples and present every monetary input, output, and export value in EUR only.
- Include exactly twelve synthetic offers across eight Sofia neighborhoods, keep real and synthetic values visibly and machine distinguishable, and never present official aggregate or municipal context as property-level evidence.
- Use reviewed NSI, BNB, Eurostat, and SofiaPlan snapshots with publisher, URL, observation date, retrieval date, unit, scope, preliminary status, license/reuse note, and limitations.
- Use a local accessible SVG schematic map with an equivalent linked list; do not present it as authoritative geometry or property due diligence.
- Generate JSON and CSV downloads from current demo state and provide a print-optimized HTML report for browser PDF output.
- Provide an interactive guided walkthrough and a locally persisted roadmap-prioritization board whose saved or exported choices are visibly non-binding and not centrally approved.
- Simulate authentication, imports, approvals, notifications, audit, and operational health; do not implement production security, live feeds, multi-user durability, legal conclusions, autonomous financial actions, or unreviewed investment recommendations.
- Do not modify public-site files or `.aib_memory/context.md`. AI Agent critique findings remain analysis-only for this experimental iteration.

## Plan

#### Intent

Create the directly openable ATISTAT-branded dashboard shell and shared runtime assets under `workdir/investment_instrument/`.

#### Procedure

1. `workdir/investment_instrument/index.html`: Create the Analyst Dashboard landing view with ranked offers, alerts, market context, tasks, prototype disclaimers, a prominent requirements link, primary workflow navigation, and a role switcher exposing lighter Administrator and Observer/Approver states.

2. `workdir/investment_instrument/assets/css/styles.css`: Define the shared responsive ATISTAT green/ink/cream visual system, local typography, layout, cards, tables, dialogs, navigation, schematic-map presentation, print behavior, visible focus, reduced-motion handling, and non-color status cues.

3. `workdir/investment_instrument/assets/fonts/bookman-cyr.woff2`: Copy the existing Cyrillic-capable ATISTAT web font into the prototype without creating an external font dependency.

4. `workdir/investment_instrument/assets/images/atistat-logo-outlined.svg`: Copy the approved outlined ATISTAT logo from `workdir/atistat-logo-outlined.svg` without changing its shapes or colors.

5. `workdir/investment_instrument/assets/js/app.js`: Implement shared relative navigation, role switching, accessible dialogs and tabs, filter/shortlist/review/tour/roadmap state, versioned local-storage persistence, safe storage fallback, visible reset, current-state JSON/CSV generation, print-report handoff, and progressive enhancement that does not depend on `fetch()` or remote services.

#### Intent

#### Procedure

3. `workdir/investment_instrument/data/offers.json`: Create exactly twelve synthetic Sofia apartment offers across exactly eight neighborhoods, including complete display, filtering, provenance-stub, version, quality, freshness, duplicate, exclusion, risk, and comparison fields with unmistakable synthetic classification.

4. `workdir/investment_instrument/data/analyses.json`: Store reproducible EUR-only profiles, assumptions, scenarios, monthly cash flows, core-calculator fixtures, labeled advanced sample outputs, risk, confidence, due-diligence checks, human-review states, and simulated audit events.

6. `workdir/investment_instrument/assets/js/demo-data.js`: Mirror the canonical runtime JSON data in a JavaScript bootstrap that works through `file://`; preserve stable identifiers and values so automated parity checks can compare it with every canonical JSON file.
