### Industry Knowledge

**Finding 1 — Viber deep-link schemes (RFC-compatible custom URI schemes):**
Viber supports two URI schemes for direct messaging actions: `viber://chat?number=<e164>` (opens a chat) and `viber://add?number=<e164>` (adds a contact). Per Viber's developer documentation and tested browser behavior, `viber://chat?number=359884074048` is the correct format for Bulgaria (+359) with the leading 0 dropped in E.164 format. WhatsApp uses `https://wa.me/<e164>` which is an HTTPS URL rather than a custom scheme, ensuring it degrades gracefully on desktop; Viber's `viber://` scheme does not open a fallback on desktop but is the standard used by Bulgarian business sites. The implementation prompt must address cross-platform behavior for Viber links.

**Finding 2 — Accessible image captions and multi-line figure text (WCAG 2.1 / HTML Living Standard):**
The HTML Living Standard recommends `<figure>` and `<figcaption>` for image captions, but the existing site uses custom `<span class="at-sketch__cap">` elements. Changing the caption structure to support three lines is best accomplished by replacing the single text node inside `at-sketch__cap` with three `<span>` elements each on a new line (rendered as a flex column or using `<br>`). Screen-reader compatibility requires the caption to remain a single `aria-label`-equivalent text node or that the parent `<a>` element carries a descriptive `aria-label`. The implementation prompt must specify that `alt` text on the image and `aria-label` on the anchor reflect the full three-line caption meaning.

**Finding 3 — Floating action button (FAB) UX patterns (Material Design / Nielsen Norman Group):**
Nielsen Norman Group research on floating action buttons indicates that a single FAB is understood immediately while multiple FABs create visual clutter. If both WhatsApp and Viber FABs are shown, they should be grouped in a single expandable FAB container (speed-dial pattern) or stacked vertically with a spacing of at least 8px. The industry best practice for mobile-first contact FABs in the Bulgarian market strongly favors Viber over WhatsApp for informal client initiation, while WhatsApp is used for international contacts. A single Viber FAB is more appropriate for ATISTAT's primary Bulgarian audience per the stakeholder's explicit decision in the xlsx.

**Finding 4 — Static-site content synchronization (no build pipeline):**
The workspace has no build system. All HTML files are independent static exports. Content synchronized across `index.html`, `index-bg.html`, `index.html?lang=bg.html`, `index-en.html`, and `index.html?lang=en.html` must be manually replicated per file. The implementation prompt must enumerate each file that requires a given change, making the AIB implement agent's work unambiguous.

**Finding 5 — WebP image optimization (Google Web Fundamentals / Lighthouse):**
Lighthouse performance guidelines recommend serving images in WebP/AVIF formats for modern browsers with a fallback `<picture>` element for older browsers. All six existing project images in `wp-content/uploads/2026/07/` are already WebP. New images supplied in PNG/JPG format should be converted to WebP before deployment. The `<img>` element naming convention follows `<project>-1-<width>x<height>.webp`. The implementation prompt should specify this conversion requirement and naming convention.
