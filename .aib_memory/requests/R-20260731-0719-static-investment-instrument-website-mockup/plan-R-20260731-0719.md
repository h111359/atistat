## Goal

Create a self-contained Bulgarian static prototype in `workdir/investment_instrument/` that vividly demonstrates the future ATISTAT residential-investment analysis concept while remaining clearly experimental, non-production, and separate from the public website. The implementation affects canonical demonstration data, offline shared assets and calculations, four primary Analyst-facing routes, one printable HTML export, local JSON/CSV samples, portable-use documentation, and `tests/test_investment_instrument_mockup.py`.

## Constraints

- The prototype must open through `file://` after ZIP extraction and must not require installation, a local server, a build step, remote runtime resources, or runtime fetching.
- Primary navigation must contain only four routes: `workdir/investment_instrument/index.html`, `workdir/investment_instrument/offers.html`, `workdir/investment_instrument/analysis.html`, and `workdir/investment_instrument/requirements.html`.
- `workdir/investment_instrument/print-report.html` is a standalone printable export linked from the analysis route, not a primary navigation destination.
- The active product view is Analyst only; Administrator and Approver responsibilities may be described, but role switching and simulated authorization are excluded.
- The dataset contains exactly twelve explicitly synthetic offers across exactly eight Sofia neighborhoods and uses EUR only.
- Official snapshots cover NSI, BNB, Eurostat, and SofiaPlan, but official aggregate data must never be presented as offer-level evidence.
- SofiaPlan is metadata-only: its official dataset page states that no license rights are specified, so the selected condition for copying real GeoJSON is unsatisfied. No coordinates, polygons, or geometry file may be copied or fabricated.
- The calculation demonstrator covers acquisition, repair, annuity financing, rental cash flow, resale, ROI, NPV, scenarios, sensitivity, risk, confidence, and invalid states without claiming approved production formulas or thresholds.
- State persistence uses a versioned `localStorage` wrapper, automatic in-memory fallback, a visible fallback notice, and visible reset.
- The design uses ATISTAT green, cream, ink, the local Bookman font, the local logo, and the visible Bulgarian label “Вътрешен експериментален прототип.”
- The export package contains sample analysis JSON, sample comparison CSV, and printable HTML suitable for browser “Save as PDF”; native PDF and XLSX generation are excluded.
- The requirements route uses a searchable formatted-verbatim presentation with section shortcuts, not a full semantic Markdown conversion, and `workdir/investment_instrument/requirements-source.md` must remain byte-identical to `workdir/investment_instrument_input.md`.
- A standalone roadmap route and roadmap persistence or export hooks are excluded; future phases remain visible only in the requirements content.
- `.aib_memory/context.md` must remain unchanged because the developer explicitly deferred context updates for this experiment.
- Existing unrelated worktree changes must be preserved.

## Success criteria

- `workdir/investment_instrument/` contains the four primary routes, `print-report.html`, all planned local assets, five canonical JSON files, two sample data exports, `requirements-source.md`, and `README.txt`.
- Every HTML document declares Bulgarian language, contains the visible experimental boundary label, uses unique identifiers, and resolves every local resource reference inside `workdir/investment_instrument/`.
- Shared navigation links exactly the four primary routes and does not expose separate offer-detail, comparison, administration, help, or roadmap routes.
- `data/offers.json` contains exactly twelve synthetic offers across exactly eight neighborhoods; all monetary offer, calculation, and export values are EUR.
- `data/market-indicators.json` and `data/source-registry.json` contain bounded NSI, BNB, Eurostat, and SofiaPlan provenance, dates, units, limitations, and non-production status.
- `data/location-context.json` records the blocked-pending-rights geography state and the eight-neighborhood list, while the prototype contains no copied or fabricated GeoJSON geometry.
- Canonical JSON data and `assets/js/demo-data.js` remain value-equivalent so all interactive routes work without `fetch()` through `file://`.
- The calculation fixtures reproduce acquisition, repair, annuity, rent, resale, ROI, NPV, and sensitivity results within a 0.01 EUR tolerance and return Bulgarian explanations for zero, invalid, missing, negative, or undefined inputs.
- Versioned local persistence, automatic in-memory fallback, visible fallback status, and reset behavior work without role or roadmap state.
- `requirements-source.md` is byte-identical to `workdir/investment_instrument_input.md`, and `requirements.html` exposes the complete escaped text with working search and section shortcuts.
- Sample JSON and CSV exports retain numeric EUR fields, provenance, version, warning, and synthetic-data labels; `print-report.html` contains the required report sections and prints without interactive controls.
- Keyboard focus, programmatic labels, non-color status cues, live recalculation messages, reduced-motion behavior, responsive layouts, and print styles are present and testable.
- `python -m unittest tests.test_investment_instrument_mockup` exits successfully with all focused tests passing.
- `/tmp/investment_instrument.zip` is created from `workdir/investment_instrument/` and `python -m zipfile -t /tmp/investment_instrument.zip` reports a valid archive.
- `.aib_memory/context.md` receives no inserts or deletions and `python .aib_brain/tools/verify-context.py --workspace .` reports all context checks passing.

#### Intent

#### Procedure

1. `workdir/investment_instrument/data/market-indicators.json`: Add bounded NSI Q1 2026 Sofia housing-price observations, BNB June 2026 housing-credit observations, one bounded Eurostat house-price observation, and a SofiaPlan metadata-only record; include publisher, source URL, observation date, retrieval date, unit, scope, preliminary status, license or reuse note, transformation, limitations, and an explicit statement that aggregate indicators are not offer evidence.
